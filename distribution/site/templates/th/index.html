ถ้า agent จ่ายเงินผ่าน POS กระเป๋าเงิน หรือ rail ของคุณ พา trust layer ไปด้วย: เผยแพร่ MCP server และ skill ของเรา ควบคู่ผลิตภัณฑ์ เพื่อให้ทุก agent ตรวจก่อนจ่ายได้

  • HTTPS call เดียวหรือ MCP tool เดียวที่เช็กเอาต์ — ไม่ต้องมี key ไม่ต้องมี wallet และอ่านอย่างเดียว
  • แพ็ก MCP server และ skill ของเราไปกับการเชื่อมต่อของคุณ; agent ของคุณได้การตรวจโดยไม่ต้องเพิ่ม vendor ที่สอง
  • คุณถือเงินและ settle เอง — Zapproof ไม่ถือหรือเคลื่อนย้ายเงิน และไม่มีค่าธรรมเนียมในการพาการตรวจไปวันนี้

สถานะจริง ไม่ใช่การตลาด

อะไรพร้อมใช้ อะไรกำลังเปิด และอะไรที่เรายังไม่ครอบคลุม

ผลิตภัณฑ์ด้านความน่าเชื่อถือที่พูดเกินขอบเขตของตัวเอง ก็เป็นเพียงคำกล่าวอ้างที่ยังไม่ถูกตรวจสอบอีกคำกล่าวอ้างหนึ่ง นี่คือแผนที่ที่ตรงไปตรงมา

พร้อมใช้วันนี้ กำลังเปิดใช้ ยังไม่ถูก index
การตรวจก่อนจ่าย REST API, remote MCP และแพ็กเกจ PyPI แบบ offline rail x402 บน Solana index จากหน้าต่าง 7 วัน (18–25 พ.ย. 2026) ด้วย fee-payer allowlist สาธารณะ Lightning และ MPP คำถามจะได้ rail_not_indexed — ขาดการครอบคลุม ไม่ใช่ข้อสรุปเชิงลบ
ดัชนี x402 บน Base settled payments 2.39M+ และผู้ขาย 19,397 ราย ณ การ build พฤศจิกายน 2026 การเชื่อมต่อ partner POS กระเป๋าเงิน และแพลตฟอร์ม agent ที่พาการตรวจไปกับผลิตภัณฑ์ คำตัดสิน ไม่มีคะแนน ป้าย หรือการอนุมัติให้จ่าย — การตีความเป็นเพียงข้อมูลหนึ่ง
