Zapproof

ดัชนีหลักฐานการชำระเงินแบบอ่านอย่างเดียวสำหรับ AI agent สร้างจากหลักฐาน การชำระเงินที่ settled แล้วบน Base ถามก่อนจ่าย: คู่ค้ารายนี้มีบันทึก การชำระเงินจริงหรือไม่ — และบันทึกนั้นบอกอะไรได้บ้าง ไม่พบข้อมูลไม่ใช่เรื่องแย่

วิธีใช้

เชื่อมต่อ remote MCP endpoint นี้:

{
  "mcpServers": {
    "zapproof": {
      "url": "__API_URL__/mcp"
    }
  }
}

มีเครื่องมือเดียว: check_counterparty ไม่ต้องมี key ไม่มี wallet และไม่มีสิทธิ์เขียนข้อมูล

แพ็กเกจ offline uvx zapproof-mcp เผยแพร่บน PyPI แล้ว ทำงานจาก snapshot ของ seller โดยไม่ต้องมี key หรือ wallet และ hosted endpoint จะใช้ได้เมื่อ /v1/health ตอบ 200 — ตรวจสถานะก่อน เชื่อถือคะแนน

hosted index ตอบฟรีวันนี้ toll 1 sat — ประมาณ 0.001 USDC บน Base — กำลังเปิดใช้ เมื่อเปิดแล้ว การขอคะแนนจะได้ 402 challenge และไฟล์ skill ภาษาไทย อธิบายการจ่ายหนึ่งครั้ง และ retry หนึ่งครั้ง

อ่านข้อจำกัดพร้อมตัวเลข

การตีความเป็นแบบ rules-based และไม่ได้ถูกตรวจสอบอย่างอิสระ การตัดสินแบบ blinded เห็นด้วยประมาณ 62% ของครั้ง (83% เมื่อไม่นับ abstentions) ผู้ตัดสินเป็น language model ไม่ใช่มนุษย์ found: false และ insufficient_evidence ไม่ใช่สัญญาณเชิงลบ และคะแนนที่เป็น null ไม่ใช่ศูนย์ Lightning ยังไม่ถูก index
