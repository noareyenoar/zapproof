ตรวจก่อนจ่าย

Zapproof ตอบคำถามเดียวเกี่ยวกับคู่ค้า: มีหลักฐานการชำระเงินอะไรอยู่ — และหลักฐานนั้นไม่ได้พิสูจน์อะไร อ่านอย่างเดียว ไม่ต้องมี key ไม่ต้องมี wallet hosted index ฟรีวันนี้; toll 1 sat กำลังเปิดใช้

เริ่มใช้

เชื่อมต่อ remote MCP endpoint นี้:

{
  "mcpServers": {
    "zapproof": {
      "url": "__API_URL__/mcp"
    }
  }
}

มีเครื่องมือเดียว: check_counterparty ไม่ต้องมี key ไม่มี wallet และไม่มีสิทธิ์เขียนข้อมูล identifier ที่รับ:

  • 0x… — EVM address ตอบจากดัชนี x402 บน Base
  • base58 key ของ Solana — ตอบจาก rail x402 บน Solana ด้วยหน้าต่างเก็บข้อมูล 7 วัน (2026-11-18 ถึง 2026-11-25) พร้อมหน้าต่างและตัวแยกประเภทกำกับ
  • EVM did: identifier เมื่อต้องการ identity binding

แพ็กเกจ offline

uvx zapproof-mcp เผยแพร่บน PyPI แล้ว ทำงานจาก snapshot ของ seller โดยไม่ต้องมี key หรือ wallet และ hosted endpoint จะใช้ได้เมื่อ /v1/health ตอบ 200 — ตรวจสถานะก่อนเชื่อถือคะแนน

toll 1 sat

hosted index ตอบฟรีวันนี้ toll 1 sat — ประมาณ 0.001 USDC บน Base — กำลังเปิดใช้ เมื่อเปิดแล้ว การขอคะแนนจะได้ 402 challenge และไฟล์ skill ภาษาไทย อธิบายการจ่ายหนึ่งครั้ง และ retry หนึ่งครั้ง แพ็กเกจ offline ยังเป็นทางที่ไม่ต้องผ่านการจ่าย

อ่านข้อจำกัดพร้อมตัวเลข

การตีความเป็นแบบ rules-based และไม่ได้ถูกตรวจสอบอย่างอิสระ การตัดสินแบบ blinded เห็นด้วยประมาณ 62% ของครั้ง (83% เมื่อไม่นับ abstentions) ผู้ตัดสินเป็น language model ไม่ใช่มนุษย์

found: false และ insufficient_evidence ไม่ใช่สัญญาณเชิงลบ และคะแนนที่เป็น null ไม่ใช่ศูนย์ ทุกคำตอบแนบหลักฐาน กฎ และข้อจำกัดของตัวเอง — รวมถึง evidence_hash ที่เก็บไว้เทียบครั้งต่อไปได้ Lightning และ MPP ยังไม่ถูก index; คำถามสำหรับ rail เหล่านั้นได้ rail_not_indexed ซึ่งหมายถึงขาดการครอบคลุม ไม่ใช่ข้อสรุปเชิงลบ
