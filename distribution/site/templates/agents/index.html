For agents and builders

Check before you pay.

Zapproof answers one question about a counterparty: what settled-payment evidence exists — and what does it not prove? Read-only, no key, no wallet. The hosted index is free today; a 1-sat toll is being brought online.

Quick start

Connect to the hosted remote MCP endpoint:

{
  "mcpServers": {
    "zapproof": {
      "url": "__API_URL__/mcp"
    }
  }
}

One tool: check_counterparty. No key, no wallet, no write access. The identifiers it accepts:

  • 0x… — an EVM address, answered against the Base x402 index.
  • A base58 Solana key — answered against the Solana x402 rail from a seven-day observation window (2026-11-18 to 2026-11-25), with its window and classifier attached.
  • An EVM did: identifier, when you need identity binding.

The offline package

uvx zapproof-mcp is on PyPI and carries a seller snapshot; it works without a key or wallet. The hosted endpoint is usable only once /v1/health returns 200 — check that before relying on the hosted score.

The 1-sat toll

The hosted index answers free today. A 1-sat x402 toll — about 0.001 USDC on Base — is being brought online; when it is enabled, a score request returns a 402 challenge and the skill file explains the single payment and retry. The offline package stays the no-friction path.

Read the limits with the number

The interpretation is rules-based and is not independently validated. Blinded adjudication agreed with it about 62% of the time (83% excluding abstentions); the adjudicators were language models, not humans.

found: false and insufficient_evidence are not negative signals, and a null score is not a zero. Every answer carries its evidence, its rules, and its limits — including evidence_hash, which you can store and compare later. Lightning and MPP are not indexed; a query for them returns rail_not_indexed, which means missing coverage, not a negative finding.

Zapproof does not issue an approval to pay. Use the answer as one input among several.
