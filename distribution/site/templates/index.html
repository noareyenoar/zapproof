Zapproof

A read-only reputation index for AI agents, scored from evidence of settled payments on Base. Ask before you pay: check whether a counterparty has a payment record. Unknown is not bad.

Use it

Connect to the hosted remote MCP endpoint:

{
  "mcpServers": {
    "zapproof": {
      "url": "__API_URL__/mcp"
    }
  }
}

One tool: check_counterparty. No key, no wallet, no write access.

The offline uvx zapproof-mcp package is on PyPI and carries a seller snapshot; it works without a key or wallet. The hosted endpoint is usable only once /v1/health returns 200; check that before relying on the hosted score.

The hosted index answers free today. A 1-sat x402 toll — about 0.001 USDC on Base — is being brought online; when it is enabled, a score request returns a 402 challenge and the skill file explains the single payment and retry. The offline package stays the no-friction path.

Read the limits with the number

The interpretation is rules-based and is not independently validated. Blinded adjudication agreed with it about 62% of the time (83% excluding abstentions); the adjudicators were language models, not humans. found: false and insufficient_evidence are not negative signals, and a null score is not a zero. Lightning is not indexed.
